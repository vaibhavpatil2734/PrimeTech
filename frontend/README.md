# World Lane Tech — Digital Studio Website

A responsive, animated React + Vite website for a web development and digital solutions startup.

## Run locally

1. Install Node.js 18+.
2. Extract the ZIP and open this folder in VS Code.
3. Open a terminal in the project directory.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. Deploy that folder to Netlify, Vercel, or any static hosting provider.

## Customize before launch

- Update the email `hello@worldlanetech.com` in `src/App.jsx` to your real business email.
- Replace the sample project previews (Made4UU, ProjectFlow, Priya Candle) with your final portfolio items.
- Edit service descriptions and company copy in `src/App.jsx`.
- The enquiry form uses `mailto:` so it opens the visitor's email app; connect a backend or form service if you want submissions stored automatically.

## Included

- Responsive layout with mobile navigation
- Framer Motion entrance animations and floating elements
- Animated orbit hero visual and scrolling marquee
- Services, portfolio, process, about, and contact sections
- Working email-enquiry form (mailto)
- Reduced-motion accessibility support
